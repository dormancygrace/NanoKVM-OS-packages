Bluetooth utilities and optional daemon with private D-Bus
Package: nkos-addon-bluez5-utils
Version: 5.87-r1

Commands: /opt/nkos/addons/bluez5-utils/bin/
Settings: /etc/kvm/bluez5-utils

Open a new terminal or source /etc/profile after installing.
Libraries are private to this package.
Enable Bluetooth with: nkos-addons enable bluez5-utils
Start Bluetooth with: nkos-addons start bluez5-utils
